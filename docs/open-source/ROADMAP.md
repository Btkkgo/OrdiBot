# OrdiBot roadmap

[English](ROADMAP.md) | [简体中文](ROADMAP.zh-CN.md)

The approved V1 scope prioritizes a usable local Mac companion. See [current verification](../CURRENT_STATUS.md) rather than treating this roadmap as completion evidence.

| Stage | Deliverable | Remaining acceptance |
| --- | --- | --- |
| G0 | Ref/dirty-work/data backup; keep/refactor/retire audit | Preserve recovery assets throughout migration |
| G1 | Compact dark Chat, original small character, single-runtime Agent expansion, native controls | Final native interaction checks |
| G2 | Explicit text/app/screenshot context; configurable streaming Model Gateway | Owner-configured real text, multi-turn, cancellation/error and vision acceptance |
| G3 | Hosted Agent adapter; actual provider records/results/approvals | Owner-configured public read-only task, polling, cancellation, approval/result acceptance |
| G4 | Isolated Windows adapters and independent native CI | Windows 11 interactive/context/API acceptance |
| G5 | Active financial retirement, branding, bilingual records, same-repository rename | Verify repository identity, history and stars after rename |

Follow-ups: English UI localization, restored image reattachment UX, more provider adapters only after verified official task APIs, and proportional usability improvements. No independent pet, autonomous local computer engine, financial product, Android automation, self-hosted cloud VM, Apple commercial signing or App Store work is planned for this V1.
