# OrdiBot roadmap

[English](ROADMAP.md) | [简体中文](ROADMAP.zh-CN.md)

The approved V1 scope prioritizes a usable local Mac companion. See [current verification](../CURRENT_STATUS.md) rather than treating this roadmap as completion evidence.

| Stage | Deliverable | Remaining acceptance |
| --- | --- | --- |
| G0 | Ref/dirty-work/data backup; keep/refactor/retire audit | Preserve recovery assets throughout migration |
| G1 | Edge Pet / Chat / Hidden / Agent; docking and geometry, native controls | Tray/hotkey acceptance; edge/click/drag and reminder metadata attachment passed |
| G2 | Metadata-only optional reminders; explicit text/screenshot context; streaming Model Gateway | Owner-configured real text, multi-turn, cancellation/error and vision acceptance |
| G3 | Models & Services, concise/normal/detailed, reminder/filter/docking preferences | Local settings persistence passed; real connection owner-deferred |
| G4 | Hosted Agent adapter; actual provider records/results/approvals | Owner-configured public read-only task, polling, cancellation, approval/result acceptance |
| G5 | Isolated Windows adapters and independent native CI | Windows 11 interactive/context/API acceptance |
| G5 | Active financial retirement, branding, bilingual records, same-repository rename | Same-repository identity/refs/139 stars verified; PR #18 merged into public main |

G6.1 implements active-UI localization and typography/theme presets; see current status for actual native acceptance. Follow-ups: restored image reattachment UX, more provider adapters only after verified official task APIs, and proportional usability improvements. No independent pet, autonomous local computer engine, financial product, Android automation, self-hosted cloud VM, Apple commercial signing or App Store work is planned for this V1.
