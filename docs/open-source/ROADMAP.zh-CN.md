# OrdiBot 路线图

[English](ROADMAP.md) | [简体中文](ROADMAP.zh-CN.md)

已确认的 V1 优先交付可用本地 Mac 助手。完成证据以[当前验证](../CURRENT_STATUS.zh-CN.md)为准，路线图不能代替验收。

| 阶段 | 交付内容 | 剩余验收 |
| --- | --- | --- |
| G0 | refs/工作区/数据备份；保留、重构、退役审计 | 持续保护恢复资产 |
| G1 | 深色紧凑 Chat、原创小角色、同运行时 Agent 展开、原生控制 | 最终原生交互检查 |
| G2 | 主动文字/应用/截图上下文；可配置流式 Model Gateway | 用户配置后真实文字、多轮、取消/错误及视觉验收 |
| G3 | 托管 Agent 适配器；真实服务记录/结果/批准 | 用户配置后公开只读任务、轮询、取消、批准/结果验收 |
| G4 | Windows 隔离适配器与独立原生 CI | Windows 11 交互、上下文和 API 验收 |
| G5 | 活跃金融业务退役、品牌、英中记录、原仓库更名 | 更名后验证仓库身份、历史与 Stars |

后续：英文界面本地化、恢复历史截图后的重新附加体验、仅基于正式任务 API 的新服务适配，以及适度易用性改进。V1 不规划独立宠物、本地自主电脑引擎、金融产品、Android 自动化、自建云端虚拟机、Apple 商业签名或 App Store 工作。
