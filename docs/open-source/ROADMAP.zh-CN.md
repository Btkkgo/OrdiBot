# OrdiBot 路线图

[English](ROADMAP.md) | [简体中文](ROADMAP.zh-CN.md)

已确认的 V1 优先交付可用本地 Mac 助手。完成证据以[当前验证](../CURRENT_STATUS.zh-CN.md)为准，路线图不能代替验收。

| 阶段 | 交付内容 | 剩余验收 |
| --- | --- | --- |
| G0 | refs/工作区/数据备份；保留、重构、退役审计 | 持续保护恢复资产 |
| G1 | Edge Pet / Chat / Hidden / Agent、停靠与位置、原生控制 | 菜单栏/快捷键及提醒点击验收；边缘/点击/拖动已通过 |
| G2 | 可关闭的仅元数据提醒；主动文字/截图；流式 Model Gateway | 用户配置后真实文字、多轮、取消/错误及视觉验收 |
| G3 | Models & Services、回答风格、提醒/过滤/停靠偏好 | 本地偏好持久化已通过；真实连接由用户暂缓 |
| G4 | 托管 Agent 适配器；真实服务记录/结果/批准 | 用户配置后公开只读任务、轮询、取消、批准/结果验收 |
| G5 | Windows 隔离适配器与独立原生 CI | Windows 11 交互、上下文和 API 验收 |
| G5 | 活跃金融业务退役、品牌、英中记录、原仓库更名 | 同仓库身份/refs/139 Stars 已验证；完成公开主线集成 |

后续：英文界面本地化、恢复历史截图后的重新附加体验、仅基于正式任务 API 的新服务适配，以及适度易用性改进。V1 不规划独立宠物、本地自主电脑引擎、金融产品、Android 自动化、自建云端虚拟机、Apple 商业签名或 App Store 工作。
