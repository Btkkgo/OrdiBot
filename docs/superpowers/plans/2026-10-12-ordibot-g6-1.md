# OrdiBot G6.1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Execute the owner's explicit request directly; retain independent final code review and real-platform evidence.

**Goal:** Upgrade existing typography, language and dark appearance without changing user data or Agent capabilities.

**Architecture:** Add defaulted native/TypeScript appearance fields. A shared typed active-UI dictionary and React UI context translate only application copy. Semantic CSS tokens control fonts, spacing and colors; draft appearance previews immediately across main and edge windows, with explicit atomic saving.

**Tech Stack:** Existing React/TypeScript, CSS, Tauri/Rust; no added runtime dependencies.

**Spec:** [Issue #20](https://github.com/Btkkgo/OrdiBot/issues/20), owner-approved G6.1 direction.

## Global constraints / 全局约束

Chinese default, English optional; scales 90/100/110/120/130; Purple/Blue/Teal/Amber/Rose; Graphite/Midnight/Warm Charcoal. Preserve histories, keys, geometry and docking. Keep the original pet's pixel size fixed. No live model call, new Agent capability, automatic X publication or history rewriting.

## Task 1: Compatible preferences / 兼容配置

- [x] Test legacy Stored deserialization with nonempty conversations/tasks/geometry; all new defaults must appear and old values survive.
- [x] Test persistence/reload for English/130/Teal/Midnight, every valid preset and invalid values; observe failure first.
- [x] Extend `companion_store.rs::Config` and `companion/types.ts::Config` with `language`, `fontScale`, `accentColor`, `backgroundStyle`, defaulting to zh-CN/100/purple/graphite. Validate native saves; retain secure credential namespace and atomic store.

## Task 2: Localized active UI / 活跃界面语言

- [x] Test dictionary/placeholder completeness, English error/status presentation, approved-origin dialog and preservation of raw provider objective/result/items.
- [x] Add `i18n/companion.ts` typed `TranslationKey`, `createCompanionTranslator(language)` and translation helpers; keep historical i18n untouched.
- [x] Translate CompanionApp, ModelSettings, AgentWorkspace, EdgeSurface and Character accessibility copy. Store error codes so switching language updates existing errors; preserve user messages and provider payloads.

## Task 3: Appearance and settings / 外观与设置

- [x] Test old preference normalization and all palette combinations' text/button/focus contrast; verify failure before implementation.
- [x] Add `companion/appearance.ts` preference normalization, semantic tokens and five font choices; `UiContext.tsx` supplies typed translations.
- [x] Replace scattered font sizes with typography tokens; scale spacing in rem, preserve pet dimensions, wrap controls and scroll forms/timeline at large text.
- [x] Add Appearance & Language first in Settings, with live preview, defaults reset and explicit save. Retain model preferences and show actual localized save failure. Synchronize appearance between main/edge via Tauri events; translate custom tray labels.

## Task 4: Acceptance and public closeout / 验收与公开收尾

- [x] Full TypeScript/Rust tests, typecheck, frontend/native signed build and independent code review; resolve findings before public integration.
- [x] Actual Mac language/scale/all-color switch, 130% Chat/Agent/Settings layout, save failure, restart persistence and Edge regressions; save local UI screenshots without user content.
- [x] New Windows CI native build; distinguish CI from unexecuted Windows GUI. Update bilingual status/logs, Issue and PR with real evidence; normal identity-safe push only.

## Review Focus / 审查重点

Legacy configurations with real histories; invalid preference saves; language changes while an error is visible; missing translated approval copy while provider data must stay untouched; contrast and fixed pet dimensions at 130%. Each has a regression or explicit native acceptance above.
